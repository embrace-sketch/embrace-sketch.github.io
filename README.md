# Сюцай Mini App — стартовый интерфейс

Это первая статическая версия интерфейса Telegram Mini App для существующего Python-бота.

## Что уже есть
- адаптивный интерфейс для телефона и Telegram;
- тёмный чёрно-золотой стиль;
- поля даты рождения и ФИО;
- выбор типа разбора: портрет, отношения, деньги/реализация;
- подключение Telegram Web Apps SDK;
- отправка JSON через `Telegram.WebApp.sendData()` при запуске из поддерживаемой Telegram-кнопки;
- демонстрационный режим при открытии в обычном браузере.

## Важно
Интерфейс пока **не подключён к логике расчётов**. Python-бот должен принимать `web_app_data`, проверять данные и вызывать существующие функции расчёта. Не помещайте токен бота или ключ Gemini в HTML/JavaScript.

`Telegram.WebApp.sendData()` подходит для Mini App, открытого через Web App keyboard button. Для запуска через меню-кнопку/основное Mini App лучше настроить защищённый API на VPS и передавать `Telegram.WebApp.initData` на сервер для проверки подписи.

## Публикация на Cloudflare Pages без GitHub
1. Откройте https://dash.cloudflare.com/
2. Перейдите в **Workers & Pages**.
3. Нажмите **Create application** → **Pages** → **Direct Upload** (названия шагов могут немного отличаться).
4. Назовите проект, например `sucai-miniapp`.
5. Загрузите ZIP-архив целиком или папку с файлом `index.html`.
6. Нажмите **Deploy site**.
7. Откройте полученный адрес вида `https://sucai-miniapp.pages.dev`.

Официальная инструкция: https://developers.cloudflare.com/pages/get-started/direct-upload/

## Следующий этап — связать с Python-ботом
После публикации:
1. Добавить обработчик `web_app_data` в `C:\sucai_bot`.
2. Преобразовать присланный JSON в параметры существующих функций расчёта.
3. Выдавать пользователю ответ/меню результата в Telegram.
4. Проверить безопасность и обработку ошибок.

Не перезаписывайте рабочий файл бота вслепую: сначала сделайте резервную копию проекта.
